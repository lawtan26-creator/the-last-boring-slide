# The Last Boring Slide (public mirror)

An interactive, self-contained HTML presentation about the singularity: one file, no external scripts, fonts, images or network calls. Works offline.

## View it

- Live site: https://lawtan26-creator.github.io/the-last-boring-slide/
- The presentation itself is `5-index.html`; `index.html` just redirects there (GitHub's web upload renamed the large file on upload).
- Or download `5-index.html` and open it in any browser. Fully self-contained, works offline.

## Controls

Arrow keys to move between slides, A for autoplay, F for fullscreen, H for speaker notes.
